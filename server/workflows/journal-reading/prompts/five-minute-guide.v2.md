仅依据输入中的论文正文块生成五分钟导读。

- 用 `problem` 说明论文解决什么问题。
- 用 `why_read` 说明为什么值得继续读，只评价论文本身，不评价当前项目价值。
- 用 `intuition` 解释方法或机制的核心直觉。
- 用 `evidence` 概括作者提供的主要证据。
- 用 `limitations` 说明论文报告的局限，或明确哪些边界仍需精读核验。
- 给出 2–3 个能够通过精读原文继续回答的问题。
- `evidence_refs` 必须包含 1–8 个输入中真实存在的 `block_id`，作为整篇导读的共同依据；不得生成页码、章节定位或输入外的引用。
- 不读取项目上下文，不评价项目价值，不补充输入中没有的事实。
